# Pallet to Pewter

An unofficial HD-2D fan remake of Pokémon FireRed / LeafGreen, played in the browser: from PALLET TOWN through all
eight gyms, VICTORY ROAD, the ELITE FOUR and the CHAMPION, MEWTWO in CERULEAN CAVE, and PROF. OAK's secret battle.
Battles are real time: moves have cooldowns, POKéMON dodge, and a full SPIRIT gauge unlocks each species' signature move.

**Play:** https://mikale4.github.io/PalletToPewter/

**Reference** (every move, every item, and a glossary of how the game plays):
https://mikale4.github.io/PalletToPewter/reference.html

- Three difficulties: NORMAL, HARD and EXTREME (six-POKéMON trainers, competitive sets, the ENDLESS CANDY).
- A self-playing **DEMO** mode that plays the whole game, start to finish, on any difficulty.
- One HTML file plus a `music/` folder; saves stay in your browser.
